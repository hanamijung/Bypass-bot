# PlatoRelay Bypass Discord Bot

บอท Discord สำหรับ bypass ลิงก์ PlatoRelay อัตโนมัติ

## การติดตั้ง

1. รัน `npm install`
2. แก้ไขไฟล์ `.env` ใส่ค่าต่างๆ
3. รัน `npm start`

## คำสั่ง

- `/bypass <url>` - Bypass ลิงก์ platorelay
- `/ping` - เช็คสถานะบอท

## ฟีเจอร์

- Auto-detect ลิงก์ platorelay ในแชท
- แสดงผลลัพธ์แบบ Embed สวยงาม
